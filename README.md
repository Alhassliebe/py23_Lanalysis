# Lana's Exes' Influence on Her Music

A one-evening fun project by two HSE University students, Anya and Alena (2023). We compared Lana Del Rey's lyrics from different periods of her personal life, using spaCy for preprocessing and word clouds to see which words dominate each period.

[Presentation with the results](https://docs.google.com/presentation/d/10U5yevlTIGTF0HyHSBWdVtNMok39K2HAhej2qfctcNY/edit?usp=sharing) (in Russian).

Code: `cloud_generator.py` (`spacy`, `wordcloud`, `matplotlib`).
